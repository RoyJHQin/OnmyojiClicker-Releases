# RandomClicker

![RandomClicker icon](assets/AppIcon.png)

一款轻量的原生 macOS 随机点击工具，可在指定范围内随机移动并点击鼠标。

## 功能

- 分别设置主要点击区域与备用区域
- 随机化点击位置和点击间隔
- 随机化每轮连续运行和休息时长
- 设置总体运行时间
- 通过全局 `Esc` 快速停止
- 自动保存本机设置

## 安装

1. 下载并解压 `RandomClicker-1.0.zip`。
2. 将 `RandomClicker.app` 移入“应用程序”文件夹。
3. 首次打开后，在“系统设置 → 隐私与安全性 → 辅助功能”中允许应用控制鼠标。
4. 如果 macOS 阻止首次启动，请右键点击应用，选择“打开”，再确认一次。

## 使用提醒

请只在你有权自动化操作的软件和界面中使用。启动前确认点击范围，运行期间可随时按 `Esc` 停止。
